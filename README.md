# exile.sh

Open-source Path of Exile 2 tools, starting with an exchange economy explorer.

Planned stack: TanStack Start on Cloudflare Workers, with Convex for data and historical ingestion. Exchange prices will come from GGG's documented public API; community item metadata will carry attribution. Launch will support public browsing and device-local favorites, with GGG account sync planned when OAuth registration is available.

## Status

Planning and research. The application has not been built or deployed yet.

- [Implementation plan](docs/plan.md)
- [API research and live observations](docs/research.md)

Cloudflare will manage branch-triggered deployments. Initial infrastructure must fit free tiers.
